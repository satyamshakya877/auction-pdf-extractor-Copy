# Auction PDF Extractor — Online Website

Deploy this folder on Streamlit Community Cloud using a GitHub repository.

1. Create a new GitHub repository (private if your hosting plan supports it).
2. Upload `app.py`, `extractor.py`, `requirements.txt`, and `.streamlit/config.toml` (preserve the folder).
3. Open https://share.streamlit.io and create a new app from that repository, main file `app.py`.
4. Once deployed, share the Streamlit URL. For Google Sites, use Insert > Embed > By URL.

Data note: Uploaded PDF data is processed on the hosting server. Use suitable private hosting for confidential documents.

Scope: tested against KCAA text-based Raku POS PDFs. Other PDF layouts/scans may require adjustments.
